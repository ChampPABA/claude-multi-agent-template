# Wireframe Patterns

ASCII art templates for common page layouts.

---

## Landing Page

### Desktop View (>1024px)
```
┌────────────────────────────────────────────────────┐
│ [Logo]        [Nav Menu]           [CTA Button]   │  ← Navbar (h-16)
├────────────────────────────────────────────────────┤
│                                                    │
│                  Hero Section                      │  ← Full viewport
│              [Large Headline]                      │
│            [Subheadline text]                      │
│              [Primary CTA]                         │
│                                                    │
├────────────────────────────────────────────────────┤
│  ┌──────────┐  ┌──────────┐  ┌──────────┐        │
│  │  Card 1  │  │  Card 2  │  │  Card 3  │        │  ← Features
│  │  [Icon]  │  │  [Icon]  │  │  [Icon]  │        │     (grid-cols-3)
│  └──────────┘  └──────────┘  └──────────┘        │
├────────────────────────────────────────────────────┤
│ [Footer Links]              [Social Icons]        │  ← Footer
└────────────────────────────────────────────────────┘
```

### Tablet View (768-1023px)
```
┌──────────────────────────────┐
│ [Logo]   [Nav]      [☰]     │
├──────────────────────────────┤
│         Hero Section         │
│       [Headline]             │
│       [CTA]                  │
├──────────────────────────────┤
│  ┌──────────┐ ┌──────────┐  │
│  │  Card 1  │ │  Card 2  │  │  ← grid-cols-2
│  └──────────┘ └──────────┘  │
│  ┌──────────┐               │
│  │  Card 3  │               │
│  └──────────┘               │
├──────────────────────────────┤
│ Footer (stacked)             │
└──────────────────────────────┘
```

### Mobile View (<768px)
```
┌────────────────┐
│ [Logo]    [☰] │
├────────────────┤
│   Hero         │
│  [Headline]    │
│  [CTA]         │
├────────────────┤
│ ┌────────────┐ │
│ │   Card 1   │ │  ← grid-cols-1
│ └────────────┘ │
│ ┌────────────┐ │
│ │   Card 2   │ │
│ └────────────┘ │
├────────────────┤
│ Footer         │
└────────────────┘
```

## Dashboard

### Desktop View
```
┌─────────────────────────────────────────────────────────────┐
│ [Logo]  [Search]                    [Notifications] [User] │  ← Top bar
├──────────┬──────────────────────────────────────────────────┤
│          │                                                  │
│  Sidebar │              Main Content Area                   │
│          │  ┌────────────┬────────────┬────────────┐       │
│  [Nav]   │  │  Stat 1    │  Stat 2    │  Stat 3    │       │  ← Stats
│  [Nav]   │  └────────────┴────────────┴────────────┘       │
│  [Nav]   │                                                  │
│  [Nav]   │  ┌─────────────────────────────────────────┐    │
│          │  │           Chart / Table                  │    │  ← Main
│          │  │                                          │    │
│          │  └─────────────────────────────────────────┘    │
│          │                                                  │
├──────────┴──────────────────────────────────────────────────┤
│ Footer (optional)                                           │
└─────────────────────────────────────────────────────────────┘
```

### Mobile View
```
┌────────────────┐
│ [☰]  [Logo]   │
├────────────────┤
│  Stats (stack) │
│  ┌──────────┐  │
│  │ Stat 1   │  │
│  └──────────┘  │
│  ┌──────────┐  │
│  │ Stat 2   │  │
│  └──────────┘  │
├────────────────┤
│  Chart/Table   │
│  (scrollable)  │
├────────────────┤
│ [Nav] [Nav]   │  ← Bottom nav
└────────────────┘
```

## Auth Page (Login/Signup)

### Desktop View
```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   ┌───────────────────────┬───────────────────────────┐   │
│   │                       │                           │   │
│   │     Illustration      │      Form Card            │   │
│   │     or Branding       │  ┌───────────────────┐   │   │
│   │                       │  │  [Logo]           │   │   │
│   │                       │  │  [Title]          │   │   │
│   │                       │  │  [Input: Email]   │   │   │
│   │                       │  │  [Input: Password]│   │   │
│   │                       │  │  [CTA Button]     │   │   │
│   │                       │  │  [Link: Forgot]   │   │   │
│   │                       │  └───────────────────┘   │   │
│   │                       │                           │   │
│   └───────────────────────┴───────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### Mobile View
```
┌────────────────┐
│                │
│    [Logo]      │
│                │
│  [Title]       │
│                │
│ ┌────────────┐ │
│ │ Email      │ │
│ └────────────┘ │
│ ┌────────────┐ │
│ │ Password   │ │
│ └────────────┘ │

│                │
```

## Spacing Reference

| Element | Desktop | Tablet | Mobile |
|---------|---------|--------|--------|
| Section padding | py-24 | py-16 | py-12 |
| Card gaps | gap-6 | gap-4 | gap-4 |
| Container | max-w-7xl | max-w-3xl | px-4 |
| Navbar height | h-16 | h-14 | h-14 |

---

## Grid Breakpoints

| Breakpoint | Width | Grid |
|------------|-------|------|
| Desktop | >1024px | 3+ columns |
| Tablet | 768-1023px | 2 columns |
| Mobile | <768px | 1 column |
